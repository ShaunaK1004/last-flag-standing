# V35.1 — Priority Spawn & Shield Fix

## Fixes
- Super Chat/Super Sticker priority spawns no longer use the normal 32-entry chat-slot cap.
- Paid priority events can create a dedicated custom flag while the arena has available capacity.
- Existing same-country flags are still reused instead of creating duplicate country flags.
- Priority Super Chat/Super Sticker shield now acts as a true one-hit elimination save for up to 10 seconds, regardless of the elimination cause.
- Shield state is cleared only after the protected hit or when the 10-second priority window expires.
- Normal chat shield behavior remains compatible.

## Existing V35 behavior preserved
- Normal user chat: normal flag + normal equipment.
- Member normal chat: Alpha + normal shotgun, no paid 2x power and no paid shield.
- Super Chat/Super Sticker from non-member: Alpha + shield + 2x shotgun.
- Super Chat/Super Sticker from member: Alpha + shield + 2x shotgun + 2x sniper.
- Priority flag duration remains 10 seconds.
- Machine Gun is not included yet.
